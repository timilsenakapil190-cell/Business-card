# Online Business Card

A personal online business card built with HTML and CSS, themed with Apple's brand color scheme.

## Project Structure

```
card/
├── index.html
├── style.css
└── README.md
```

## Requirements Met

| Requirement         | Implementation                                         |
| ------------------- | ------------------------------------------------------ |
| External Stylesheet | `<link rel="stylesheet" href="style.css">` in `<head>` |
| Brand Color Scheme  | Apple official HEX colors in `style.css`               |
| ID Selector         | `#profile-name` — styles the name heading              |
| Class Selector      | `.card-info` — styles contact detail paragraphs        |

## Brand Colors (Apple)

| Color           | HEX       | Usage              |
| --------------- | --------- | ------------------ |
| Apple Gray      | `#F5F5F7` | Page background    |
| Apple Black     | `#1D1D1F` | Primary text       |
| Apple Blue      | `#0071E3` | Link/button accent |
| Apple Gray Text | `#6E6E73` | Secondary text     |
| Apple Border    | `#D2D2D7` | Divider lines      |

## How to View

Open `index.html` in any web browser.

## Personalization

Edit the text content in `index.html` to replace placeholder info with your own name, title, location, email, and phone number.
