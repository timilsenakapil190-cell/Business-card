# Online Business Card

A personal online business card built with HTML and CSS, using an Apple-inspired visual style and a clean, modern layout.

## Overview

This project was created as a simple digital business card that displays:

- name
- job title
- location
- email address
- phone number
- a shortcut resource link to a Google Doc

## Project Structure

```
Business-card/
├── index.html
├── style.css
├── README.md
└── .gitignore
```

## What I Built

### HTML structure

The page was created in `index.html` with:

- a centered business card container
- a header section for the name and title
- contact details formatted with the `.card-info` class
- a button-style link for the Google Doc shortcut
- a footer with copyright text

### CSS styling

The design in `style.css` includes:

- a full-page neutral background using `#F5F5F7`
- dark text using `#1D1D1F`
- a white card container with rounded corners and subtle shadow
- `#profile-name` styling for the main heading
- `.card-info` styling for contact details
- a blue accent color for the shortcut link using `#0071E3`
- divider lines and consistent spacing for a polished card layout

## Requirements Met

| Requirement         | Implementation                                             |
| ------------------- | ---------------------------------------------------------- |
| External Stylesheet | `<link rel="stylesheet" href="style.css">` in the `<head>` |
| Brand Color Scheme  | Apple-inspired colors defined in `style.css`               |
| ID Selector         | `#profile-name` for the name heading                       |
| Class Selector      | `.card-info` for contact detail text                       |

## Brand Colors (Apple-inspired)

| Color           | HEX       | Usage                  |
| --------------- | --------- | ---------------------- |
| Apple Gray      | `#F5F5F7` | Page background        |
| Apple Black     | `#1D1D1F` | Primary text           |
| Apple Blue      | `#0071E3` | Link and button accent |
| Apple Gray Text | `#6E6E73` | Secondary text         |
| Apple Border    | `#D2D2D7` | Divider lines          |
